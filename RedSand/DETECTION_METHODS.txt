# RedSand Secure - Методы обнаружения вредоносного ПО

## Как мы определяем что файл опасен

RedSand Secure использует многоуровневую систему анализа для выявления вредоносного программного обеспечения.

### 1. Сигнатурный анализ

Мы используем базу данных известных вредоносных сигнатур для идентификации угроз:

- **Вирусы (Virus)**: Файлы, содержащие код известных вирусов
- **Трояны (Trojan)**: Программы, маскирующиеся под легитимное ПО
- **Черви (Worm)**: Самовоспроизводящиеся программы
- **Шпионское ПО (Spyware)**: Программы для сбора конфиденциальной информации
- **Рекламное ПО (Adware)**: Нежелательные программы показа рекламы
- **Майнеры (Miner)**: Программы для скрытого майнинга криптовалют
- **Рансомваре (Ransomware)**: Программы-вымогатели
- **Руткиты (Rootkit)**: Программы для скрытия присутствия вредоносного ПО

### 2. Анализ подозрительных паттернов

Система выявляет подозрительное поведение и паттерны в коде:

- **Подозрительные импорты**: Импорт модулей для работы с реестром, процессами, памятью
- **Обфускация кода**: Использование base64, eval, exec для скрытия кода
- **Сетевая активность**: Попытки подключения к удалённым серверам
- **Работа с файлами**: Массовое шифрование, удаление файлов
- **Автозагрузка**: Добавление себя в автозагрузку системы
- **Инъекции кода**: Впрыскивание кода в другие процессы

### 3. Статический анализ

Анализ файла без его выполнения:

- Проверка заголовков PE-файлов
- Анализ импортируемых функций
- Поиск строковых литералов
- Выявление упаковщиков и протекторов
- Анализ секций executable файла

### 4. Классификация угроз

На основе анализа файлы классифицируются по уровням опасности:

#### 🔴 ОПАСНЫЙ (MALICIOUS)
- Risk Score: 70-100
- Содержит известные вредоносные сигнатуры
- Обнаружено множественное совпадение с угрозами
- Выявлено критическое подозрительное поведение
- **Рекомендация**: Немедленно поместить в карантин и удалить

#### ⚠️ ПОДОЗРИТЕЛЬНЫЙ (SUSPICIOUS)
- Risk Score: 30-69
- Обнаружены отдельные подозрительные элементы
- Частичное совпадение с известными угрозами
- Необычное поведение для данного типа файлов
- **Рекомендация**: Поместить в карантин для дальнейшего анализа

#### ✅ БЕЗОПАСНЫЙ (CLEAN)
- Risk Score: 0-29
- Не обнаружено известных сигнатур
- Нет подозрительных паттернов
- Поведение соответствует заявленному типу файла
- **Рекомендация**: Файл безопасен для использования

### 5. Автоматический карантин

Все файлы classified как ОПАСНЫЕ или ПОДОЗРИТЕЛЬНЫЕ автоматически помещаются в карантин:

- Файл перемещается в защищённую директорию
- Оригинальный путь сохраняется в журнале
- Файл не может быть выполнен или нанести вред
- Пользователь может восстановить или удалить файл навсегда

### 6. Журналирование и отчётность

Каждый анализ подробно документируется:

- Время и дата сканирования
- Путь к файлу и его хэш
- Обнаруженные угрозы и сигнатуры
- Совпавшие паттерны поведения
- Присвоенный уровень опасности
- Рекомендации по действиям

---

**Важно**: RedSand Secure постоянно обновляет базу сигнатур и улучшает алгоритмы обнаружения для защиты от новых угроз.
