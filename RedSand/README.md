# RedSand Secure Sandbox

**Система анализа вредоносного ПО с максимальной безопасностью**

RedSand — это локальная песочница для безопасного анализа подозрительных файлов (exe, dll, скрипты) на Windows. Система автоматически отключает сеть, классифицирует угрозы и генерирует детальные отчеты.

## ⚠️ ТРЕБОВАНИЯ БЕЗОПАСНОСТИ

1. **Запускать ТОЛЬКО в изолированной виртуальной машине** (VirtualBox, VMware)
2. **Только Windows** (требуется PowerShell и netsh)
3. **Запуск от имени АДМИНИСТРАТОРА** (для управления сетью)
4. **Снапшот ВМ**: Перед запуском сделайте чистый снапшот системы

## 🚀 Возможности

### Безопасность
- ✅ Полное отключение всех сетевых адаптеров (Wi-Fi, Ethernet)
- ✅ Блокировка всего трафика через Windows Firewall
- ✅ Автоматическое восстановление сети после анализа
- ✅ Экстренное восстановление при сбоях

### Классификация угроз
Система определяет тип вируса:
- **Ransomware** (шифровальщики)
- **Stealer** (похитители данных)
- **Miner** (майнеры)
- **RAT** (трояны удаленного доступа)
- **Botnet** (бот-сети)
- **Dropper** (загрузчики)

### Анализ
- Статический анализ (сигнатуры в байтах файла)
- Динамический анализ (поведенческие паттерны)
- Сопоставление с **MITRE ATT&CK**
- Расчет уровня риска (0-100)

### Отчетность
- Детальный JSON отчет
- Логи событий
- Рекомендации по устранению

## 🔧 Установка

### На хосте (Linux/Mac):
```bash
git clone <repo_url>
cd RedSand
# Только просмотр кода, запуск только на Windows VM!
```

### На гостевой Windows VM:
1. Установите Python 3.9+
2. Скопируйте файлы `redsand_secure.py` и `agent.cpp` в ВМ
3. Для компиляции агента (опционально):
   ```bash
   # Требуется MinGW или Visual Studio
   g++ -o agent.exe agent.cpp -lws2_32
   ```

## 💻 Использование

### Базовый запуск (Python оркестратор):
```powershell
# От имени Администратора!
python redsand_secure.py C:\path\to\suspicious_file.exe
```

### Что происходит при запуске:
1. ⛔ **Отключение сети**: Все адаптеры блокируются
2. 🔍 **Статический анализ**: Поиск сигнатур в файле
3. 🚀 **Динамический анализ**: Запуск образца (через агент)
4. 📊 **Классификация**: Определение типа угрозы
5. ✅ **Восстановление**: Сеть включается обратно
6. 📝 **Отчет**: Сохранение в `reports/`

### Пример вывода:
```

Угроза: Ransomware
Риск: 85/100
Описание: Шифровальщик файлов. Требует выкуп за расшифровку.
MITRE: T1486, T1490
```

## 🛡️ Как это работает

### 1. Изоляция сети
Скрипт использует `netsh` для:
- Отключения всех интерфейсов (`admin=disabled`)
- Добавления правил Firewall (блок всего входящего/исходящего)

### 2. Классификатор
Ищет сигнатуры в байтах файла:
- Ransomware: `encrypt`, `bitcoin`, `.onion`
- Stealer: `password`, `cookie`, `telegram`
- Miner: `stratum`, `xmr`, `pool`

### 3. Агент (C++)
Мониторит в реальном времени:
- Создание новых процессов
- Подозрительные файлы (`.encrypted`, `.lock`)
- Сетевые подключения (порты 4444, 8080)
- Ключи автозагрузки в реестре

## ⚙️ Расширение функционала

```bash

g++ -o agent.exe agent.cpp -lws2_32 -static

# Visual Studio
cl /EHsc agent.cpp
```

### Интеграция с оркестратором:
В `redsand_secure.py` замените блок эмуляции на:
```python
subprocess.run(['agent.exe', sample_path], check=True)
# Парсинг логов из logs/agent_activity.log
```
