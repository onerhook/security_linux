# 🛡️ RedSand Secure v2.0

**Максимально безопасная система анализа вредоносного ПО для локального использования**

> ⚠️ **ВНИМАНИЕ**: Запускать ТОЛЬКО в изолированной виртуальной машине (VM)!

## 📋 Описание

RedSand Secure - это автономная песочница для анализа подозрительных файлов, работающая полностью локально без внешних серверов. Система обеспечивает максимальную безопасность за счет полного отключения сети во время анализа и эмуляции сетевой активности.

### ✨ Ключевые возможности

- 🔒 **Полная изоляция** - автоматическое отключение Wi-Fi/Ethernet и блокировка фаервола
- 🎭 **Сетевая эмуляция** - локальные DNS/HTTP серверы для перехвата запросов
- 🚨 **Panic Button** - мгновенная остановка при критических действиях
- 🧬 **Полиморфный анализ** - генерация вариантов образцов для проверки эвристик
- 🦠 **12 типов угроз** - классификация: Ransomware, Stealer, Miner, RAT, Worm, Botnet, Rootkit, Spyware, Adware, Trojan, Dropper, Keylogger
- 📊 **MITRE ATT&CK** - сопоставление тактик противника
- 📝 **3 формата отчетов** - JSON, HTML (интерактивный), TXT

## 🚀 Быстрый старт

### Требования

- **ОС**: Windows 10/11 (анализ), Linux/macOS (разработка)
- **Python**: 3.9+
- **Права**: Администратор (для отключения сети)
- **Зависимости**:
  ```bash
  pip install pefile yara-python psutil
  ```

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/YOUR_USERNAME/RedSand_Secure.git
   cd RedSand_Secure
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите в виртуальной машине!

## 📖 Использование

### Анализ файла

```bash
python redsand_secure.py suspicious.exe
```

### С полиморфным анализом

```bash
python redsand_secure.py malware.dll --poly
```

### Генерация тестовых симуляторов

```bash
python redsand_secure.py --generate-test-samples
```

Это создаст 12 безопасных BAT-файлов, имитирующих поведение различных типов угроз.

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `file` | Файл для анализа |
| `--poly` | Использовать полиморфный анализ |
| `--timeout N` | Таймаут динамического анализа (сек, по умолчанию 60) |
| `--generate-test-samples` | Сгенерировать тестовые образцы |
| `--output DIR` | Директория для отчетов (по умолчанию `reports`) |

## 🔒 Меры безопасности

### Автоматическая защита

1. **Отключение сети** - все адаптеры (Wi-Fi, Ethernet) отключаются через `netsh`
2. **Блокировка фаервола** - правила блокируют весь входящий/исходящий трафик
3. **Эмуляция сети** - образец "думает", что сеть доступна
4. **Мониторинг процессов** - отслеживание критических действий
5. **Экстренная остановка** - убийство процессов при угрозе
6. **Автоматическое восстановление** - сеть включается после анализа

### Panic Button

Система автоматически обнаруживает и останавливает:
- Команды форматирования/удаления файлов
- Попытки изменения реестра
- Подозрительные процессы (mimikatz, procdump, psexec)
- PowerShell с кодированными командами

## 📊 Отчеты

### Форматы

- **JSON** - полные данные для машинной обработки
- **HTML** - интерактивный отчет с визуализацией
- **TXT** - текстовая версия для печати

### Содержимое отчета

- Информация о файле (хеши, размер, тип)

- Классификация угрозы (тип, семейство, риск)
- MITRE ATT&CK тактики
- Извлеченные IOC (индикаторы компрометации)

## ⚙️ Настройка

### YARA правила

Добавьте свои правила в папку `rules/`:
```yara
rule MyMalwareRule {
    strings:
        $s1 = "suspicious_string"
    condition:
        $s1
}
```

### Конфигурация сети

Измените порты в `modules/network_emulator.py`:
```python
dns_port=53   # DNS сервер
http_port=80  # HTTP сервер
```

## ⚠️ Предупреждения

1. **Запускайте ТОЛЬКО в VM** - никогда на хост-системе!
2. **Требуются права админа** - для отключения сети
3. **Делайте снапшот VM** - перед каждым анализом
4. **Изолируйте сеть VM** - режим Host-Only или NAT
5. **Не анализируйте реальное вредоносное ПО** без должной подготовки
