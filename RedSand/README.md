# RedSand - Malware Sandbox Analysis System

## Описание
Локальная система анализа вредоносного ПО для Windows с минимальными требованиями к инфраструктуре.
Использует ETW (Event Tracing for Windows) для мониторинга и перехвата системных вызовов.

## Структура проекта
```
RedSand/
├── src/
│   ├── orchestrator.py      # Python контроллер
│   ├── agent.cpp            # C++ агент мониторинга (Windows)
│   ├── analyzer.py          # Движок анализа
│   └── reporter.py          # Генератор отчетов
├── bin/
│   └── RedSandAgent.dll     # Скомпилированный агент
├── logs/                    # Логи работы системы
├── samples/                 # Образцы для анализа
├── reports/                 # Сгенерированные отчеты
└── README.md
```

## Требования
- **ОС**: Windows 10/11 (для анализа), Linux (для разработки)
- **Python**: 3.9+
- **Компилятор**: Visual Studio 2019+ или MinGW-w64
- **Зависимости**: 
  - Python: `pip install pywin32 psutil yara-python`
  - C++: Windows SDK, MinHook (опционально)

## Быстрый старт

### 1. Сборка агента (на Windows)
```bash
# Используем Visual Studio
cl /LD src/agent.cpp /Fe:bin/RedSandAgent.dll /link kernel32.lib advapi32.lib

# Или MinGW
g++ -shared -o bin/RedSandAgent.dll src/agent.cpp -lkernel32 -ladvapi32
```

### 2. Запуск анализа
```bash
python src/orchestrator.py --sample samples/suspicious.exe --output reports/report.json
```

### 3. Просмотр отчета
```bash
python src/reporter.py --input reports/report.json --format html
```

## Архитектура

### Компоненты:

1. **Orchestrator (Python)**
   - Управление жизненным циклом анализа
   - Запуск образца в изолированной среде
   - Координация сбора данных

2. **Monitoring Agent (C++)**
   - Перехват событий через ETW
   - Мониторинг файлов, реестра, сети, процессов
   - Отправка событий оркестратору

3. **Analyzer (Python)**
   - Построение графа поведения
   - Расчет риска
   - Извлечение IOC

4. **Reporter (Python)**
   - Генерация JSON отчета
   - Создание человекочитаемого отчета

## Уникальные особенности

- **Легковесность**: Работает без виртуализации, минимальные накладные расходы
- **Глубокий мониторинг**: ETW предоставляет доступ к низкоуровневым событиям
- **Быстрый анализ**: Нет необходимости в снапшотах ВМ
- **Локальность**: Все данные остаются на компьютере пользователя

## Меры безопасности

⚠️ **ВНИМАНИЕ**: Система предназначена для запуска только в изолированной среде!
- Используйте выделенную виртуальную машину для анализа
- Не запускайте на основной рабочей системе
- Ограничьте сетевой доступ во время анализа

## Пример отчета

Отчет содержит:
- Временную шкалу событий
- Изменения в файловой системе
- Модификации реестра
- Сетевую активность
- Дерево процессов
- Рассчитанный риск и вердикт
