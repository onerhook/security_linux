# 🛡️ RedSand Secure Sandbox

Профессиональная система анализа вредоносного ПО с открытым исходным кодом, вдохновленная Cuckoo Sandbox. Обеспечивает безопасный статический и динамический анализ подозрительных файлов в изолированной среде.

## ⚠️ ПРЕДУПРЕЖДЕНИЕ О БЕЗОПАСНОСТИ

**Запускайте ТОЛЬКО в изолированной виртуальной машине или Docker контейнере!**

Эта система предназначена для анализа реального вредоносного ПО. Никогда не запускайте её на основной операционной системе.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Генерация тестовых образцов

```bash
python samples/generate_samples.py
```

### Запуск GUI (рекомендуется)

```bash
python run.py --gui
```

Или просто:

```bash
python run.py
```

### Запуск CLI

```bash
python run.py --cli --file samples/fake_trojan_XYZ.exe --output reports
```

## 🔍 Возможности

### Статический анализ
- Анализ PE заголовков и структуры файлов
- Извлечение строк и поиск IOC
- Сигнатурное сканирование
- Хэширование (MD5, SHA1, SHA256)
- Анализ импортов/экспортов

### Динамический анализ (Cuckoo-like)
- Изолированное выполнение кода
- Мониторинг системных вызовов
- Отслеживание операций с файлами
- Сетевая активность
- Манипуляции с процессами
- Попытки внедрения кода

### Классификация угроз
Поддержка 12 типов угроз:
- 🐴 Trojan (Трояны)
- 🔒 Ransomware (Шифровальщики)
- 👁️ Spyware (Шпионское ПО)
- 📢 Adware (Рекламное ПО)
- 🪱 Worm (Сетевые черви)
- 🕵️ Rootkit (Скрытые угрозы)
- ⛏️ Miner (Майнеры)
- 🗑️ Backdoor (Бэкдоры)
- 🎣 Keylogger (Кейлоггеры)
- 🌐 Botnet (Ботнеты)
- 💉 Dropper (Загрузчики)
- 🔧 Exploit (Эксплойты)

### Дополнительные функции
- **MITRE ATT&CK Mapping**: Сопоставление техник атак
- **Полиморфный анализ**: Обнаружение метаморфных модификаций
- **Anti-Sandbox Detection**: Выявление попыток обхода песочницы
- **Panic Button**: Мгновенная остановка всех процессов
- **Multiprocessing**: Параллельный анализ нескольких файлов
- **Детальные отчеты**: JSON, HTML, PDF форматы

## 🛡️ Безопасность

### Уровни защиты
1. **Изоляция процессов**: Каждый анализ в отдельном процессе
2. **Mock-окружение**: Подмена опасных API
3. **Таймауты**: Автоматическая остановка зависших анализов
4. **Лимиты памяти**: Защита от DoS
5. **Сетевая изоляция**: Эмулированный сетевой стек
6. **AppArmor/SELinux**: Профили безопасности (опционально)
7. **Seccomp-bpf**: Фильтрация системных вызовов

### Panic Button
При обнаружении критической угрозы:
- Немедленная终止 всех дочерних процессов
- Очистка временных файлов
- Блокировка сетевых соединений
- Сохранение логов инцидента

## 🔧 Конфигурация

Настройки находятся в `core/orchestrator.py`:

```python
SANDBOX_TIMEOUT = 30  # Секунд на анализ
MAX_MEMORY_MB = 512   # Лимит памяти
ENABLE_NETWORK = True # Эмуляция сети
DEEP_ANALYSIS = False # Глубокий анализ (медленнее)
```
