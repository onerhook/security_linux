## 🚀 Как использовать

### Запуск:
```bash
cd /workspace/RedSand
python3 run.py
```

### Структура приложения:

```
Главный экран
├── 🛡️ АНТИВИРУС → Панель антивируса
│   ├── ВКЛ/ВЫКЛ защита
│   ├── Мониторинг папок
│   ├── Журнал событий
│   └── ← Назад
│
├── 🔍 АНАЛИЗ ФАЙЛОВ → Панель анализа
│   ├── Выбор файла
│   ├── Настройки
│   ├── Прогресс
│   ├── Логи
│   ├── Результаты
│   └── ← Назад
│
├── ⚙ Настройки (диалог)
├── 📜 История (диалог)
└── ⚠️ Карантин (диалог)
```

### Навигация:
1. При запуске видите главный экран
2. Выбираете режим (Антивирус или Анализ)
3. Работаете в режиме
4. Кнопка "← Назад" возвращает на главный экран
5. Карантин, настройки и история доступны везде
