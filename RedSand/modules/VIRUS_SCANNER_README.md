# Virus Scanner - Новый модуль проверки на вирусы

## Обзор

`virus_scanner.py` - это полностью новый модуль проверки на вирусы, созданный с нуля для проекта RedSand Secure. Модуль использует многоуровневую систему детектирования вредоносного ПО.

## Компоненты системы

### 1. Сигнатурный анализ
- Проверка по базе известных хешей вредоносных файлов
- Поддержка MD5, SHA1, SHA256
- Fuzzy hashing (SSDeep) для поиска похожих файлов

### 2. Эвристический анализ
- Обнаружение подозрительных паттернов в коде
- Анализ PowerShell обфускации
- Детектирование C2 коммуникаций
- Распознавание техник обхода анализа

### 3. PE анализ (для Windows исполняемых файлов)
- Парсинг заголовков PE файлов
- Анализ секций на подозрительность
- Проверка флагов безопасности (ASLR, DEP/NX)
- Детектирование RWX секций

### 4. Анализ энтропии
- Вычисление энтропии Шеннона
- Обнаружение упаковщиков и шифровальщиков
- Посекционный анализ файла

### 5. Классификация угроз
Поддержка 14 типов угроз:
- Ransomware (шифровальщики)
- Trojan (трояны)
- Worm (черви)
- Virus (вирусы)
- Spyware (шпионское ПО)
- Adware (рекламное ПО)
- Rootkit (руткиты)
- Miner (майнеры)
- RAT (удаленное управление)
- Stealer (похитители данных)
- Botnet (ботнеты)
- Dropper (загрузчики)
- Keylogger (кейлоггеры)
- Backdoor (бэкдоры)

## Использование

### Базовое сканирование файла

```bash
python modules/virus_scanner.py suspicious_file.exe
```

### Подробный вывод

```bash
python modules/virus_scanner.py suspicious_file.exe -v
```

### Сканирование директории

```bash
python modules/virus_scanner.py --dir ./samples --recursive
```

### Вывод в JSON формате

```bash
python modules/virus_scanner.py file.dll --json
```

### Сохранение результатов

```bash
python modules/virus_scanner.py malware.exe -o report.json
```

### Использование кастомных правил

```bash
python modules/virus_scanner.py file.exe --rules custom_rules.json
```

## Формат кастомных правил

```json
[
  {
    "name": "Custom Malware Hash",
    "type": "hash",
    "value": "sha256_hash_here",
    "risk": 90
  },
  {
    "name": "Suspicious Pattern",
    "type": "pattern",
    "pattern": "(?i)suspicious_regex",
    "risk": 50
  }
]
```

## Уровни угрозы

- **SAFE** (0-19): Файл не показывает признаков вредоносности
- **LOW** (20-39): Некоторые подозрительные элементы
- **MEDIUM** (40-59): Значительные подозрительные признаки
- **HIGH** (60-79): Высокая вероятность вредоносности
- **CRITICAL** (80-100): Явные признаки вредоносного ПО

## Интеграция с другими модулями

Модуль может быть использован как самостоятельный инструмент или интегрирован в основную систему RedSand Secure:

```python
from modules.virus_scanner import VirusScanner

scanner = VirusScanner()
result = scanner.scan_file('suspicious.exe')

print(f"Уровень угрозы: {result.threat_level.value}")
print(f"Риск: {result.risk_score}/100")
print(f"Семейство: {result.malware_family.value}")

# Получение статистики
stats = scanner.get_scan_statistics()
print(f"Всего сканирований: {stats['total_scans']}")
```

## Преимущества новой системы

1. **Полностью переписан с нуля** - чистая архитектура без legacy кода
2. **Многоуровневая защита** - комбинация различных методов детектирования
3. **Быстрая работа** - оптимизированные алгоритмы
4. **Гибкость** - поддержка кастомных правил
5. **Подробные отчеты** - детальная информация о найденных угрозах
6. **Кроссплатформенность** - работает на Windows, Linux, macOS
7. **Нет внешних зависимостей** - использует только стандартную библиотеку Python
