# 🔒 Инструкция по безопасности RedSand

## КРИТИЧЕСКИ ВАЖНО

Данная система предназначена для анализа ВРЕДОНОСНОГО ПРОГРАММНОГО ОБЕСПЕЧЕНИЯ.
Неправильное использование может привести к:
- Заражению вашей основной системы
- Утечке конфиденциальных данных
- Повреждению файлов
- Сетевым атакам через ваш компьютер

## ✅ Правила безопасного использования

### 1. Подготовка виртуальной машины

```
[Хост-машина (Linux/Mac)]
    ↓
VirtualBox / VMware
    ↓
[Гостевая ОС: Windows 10/11 ISO]
    ├── Отключить общие папки
    ├── Отключить буфер обмена
    ├── Отключить Drag-n-Drop
    ├── 1 CPU, 2GB RAM (минимум)
    └── Сделать СНЭПШОТ "Clean State"
```

### 2. Настройка сети ВМ

Перед запуском анализа:
1. **Отключите сетевой адаптер ВМ** в настройках гипервизора
2. Убедитесь, что нет доступа к локальной сети хоста
3. Проверьте, что общие папки отключены

### 3. Запуск анализа

```powershell
# Внутри Windows VM, от имени АДМИНИСТРАТОРА
cd C:\RedSand
python redsand_secure.py C:\samples\suspicious.exe
```

### 4. После анализа

1. Дождитесь сообщения "Сеть восстановлена"
2. Проверьте логи на наличие ошибок
3. **ВОССТАНОВИТЕ СНЭПШОТ** "Clean State"
4. Только после этого копируйте новый образец

## 🚨 Экстренные действия

### Если вирус сбежал из песочницы:

1. **НЕМЕДЛЕННО ОТКЛЮЧИТЕ КОМПЬЮТЕР ОТ СЕТИ** (выдерните кабель)
2. Завершите процесс `python.exe` в диспетчере задач
3. Восстановите систему из снапшота
4. Просканируйте хост-машину антивирусом

### Если скрипт завис:

```powershell
# Принудительная остановка
Ctrl+C в консоли

# Если не помогло - завершите процесс
taskkill /F /IM python.exe

# Восстановление сети вручную
netsh advfirewall firewall delete rule name="RedSand_Block_All_Out"
netsh advfirewall firewall delete rule name="RedSand_Block_All_In"
netsh interface set interface "Ethernet" admin=enabled
```

## ⚙️ Технические детали безопасности

### Как работает изоляция:

1. **Уровень 1**: Отключение сетевых адаптеров через `netsh`
   ```
   netsh interface set interface "Ethernet" admin=disabled
   ```

2. **Уровень 2**: Блокировка фаерволом
   ```
   netsh advfirewall firewall add rule name="RedSand_Block_All_Out" dir=out action=block
   ```

3. **Уровень 3**: Эмуляция сети (DNS/HTTP серверы)
   - Вирус "думает", что сеть есть
   - Все запросы остаются внутри ВМ

4. **Уровень 4**: Автоматическое восстановление
   - Даже при крахе скрипта сеть включится обратно

### Ограничения:

⚠️ Система НЕ защищает от:
- Уязвимостей в гипервизоре (VM escape)
- Атак через общие ресурсы (если не отключены)
- Человека (случайный запуск на хосте)

1. Проверьте логи в `logs/redsand.log`
2. Восстановите снапшот
3. Попробуйте запустить с другим образцом
