# 🛡️ RedSand Secure GUI - Современный интерфейс анализа вредоносного ПО

## 📋 Описание

Красивый и функциональный GUI интерфейс для системы анализа вредоносного ПО RedSand Secure с поддержкой:

- **6 тем оформления**: Тёмная, Светлая, Киберпанк, Океан, Лес, Полночь
- **2 языка**: Русский 🇷🇺 и English 🇬🇧
- **Множество настроек**: Более 30 параметров конфигурации
- **4 вкладки**: Анализ, Настройки, Отчёты, Логи

## 🚀 Запуск

```bash
# Установка зависимостей
pip install PyQt6

# Запуск GUI
python gui.py

# Или через headless режим (для серверов)
QT_QPA_PLATFORM=offscreen python gui.py
```

## ✨ Возможности

### Вкладка "Анализ"
- Выбор файла/папки для анализа
- Настройки статического анализа (PE, строки, хеши, YARA)
- Настройки динамического анализа (запуск, мониторинг процессов/сети/реестра)
- Эмуляция сети (DNS, HTTP)
- Анти-песочница (фейк активность, реестр, процессы)
- Прогресс бар и статистика
- Логи в реальном времени

### Вкладка "Настройки"
- **Анализ**: глубина сканирования, чувствительность, эвристика, ML, облако
- **Поведение**: автоудаление, карантин
- **Безопасность**: изоляция сети, песочница
- **Интерфейс**: выбор темы, языка, логирование, трей
- **Дополнительно**: автостарт, автообновление баз

### Вкладка "Отчёты"
- История всех сканирований
- Предпросмотр отчётов
- Экспорт в JSON/HTML/TXT

### Вкладка "Логи"
- Детальные логи анализа
- Цветное кодирование событий
- Очистка логов

## 🔧 Интеграция с redsand_secure.py

Для полноценной интеграции с движком анализа:

1. В методе `AnalysisWorker.run()` замените симуляцию на вызов:
```python
from redsand_secure import RedSandSecure
analyzer = RedSandSecure()
result = analyzer.analyze_file(self.file_path)
```

2. Обновите обработку результатов в `handle_result()`

3. Добавьте поддержку форматов отчётов из `report_generator.py`
