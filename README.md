# 🤖 Многофункциональный Telegram Бот

Мощный бот для мониторинга сервера, Steam аккаунта, промокодов и управления хостингом.

## 🚀 Возможности

### 📊 Статистика сервера
- Загрузка CPU в реальном времени
- Использование RAM (GB)
- Использование диска (GB)
- Кнопка обновления данных

### 💰 HostVDS Интеграция
- Проверка баланса счета
- Информация о сервере (требуется Server ID)
- *Планируется:* автоматическая установка пакетов

### 🎮 Steam Функции
- **Скидки в желаемом** - мониторинг акций на игры из вашего wishlist
- **Инвентарь CS:GO** - просмотр предметов инвентаря
- **Уровень аккаунта** - отображение уровня Steam профиля
- **Трейд-офферы** - активные обменные предложения
- **Торговая площадка** - поиск предметов (в разработке)

### 🔍 Мониторинг промокодов
- **Автоматический мониторинг** каждые 5 минут
- **Promocodus.ru** - промокоды для CaseBattle и других сайтов
- **CaseBattle.io** - акции и специальные предложения
- **Steam Specials** - крупные распродажи
- Мгновенные уведомления в чат о новых промокодах

### 🎁 Планируемые функции
- Автозакуп подарков в Telegram
- Улучшение подарков с красивыми номерами
- Расширенное управление HostVDS (автоустановка пакетов)
- Сбор детальной статистики
- Больше Steam интеграций

## ⚙️ Настройка

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Конфигурация (`bot/config.py`)

Заполните следующие поля:

```python
# Telegram Bot Token
BOT_TOKEN = "ваш_токен_бота"

# Steam Account
STEAM_USERNAME = "ваш_login_steam"
STEAM_PASSWORD = "ваш_пароль_steam"
STEAM_REGION = "KZ"  # Регион (Казахстан)
STEAM_SHARED_SECRET = ""  # shared_secret из maFiles если включен 2FA

# HostVDS
HOSTVDS_LOGIN = "ваш_логин_hostvds"
HOSTVDS_PASSWORD = "ваш_пароль_hostvds"
HOSTVDS_SERVER_ID = ""  # ID сервера (опционально)

# Admin
ADMIN_ID = 1206423837  # Ваш Telegram ID
```

### 3. Steam Guard (2FA)

Если у вас включена двухфакторная аутентификация:

1. Установите Steam Desktop Authenticator (SDA)
2. Найдите файл `maFiles` с данными аккаунта
3. Скопируйте `shared_secret` в `config.py`

Или временно отключите Steam Guard для тестирования.

## 📱 Использование

После запуска отправьте боту команду `/start` или нажмите кнопку в Telegram.

### Доступные команды:
- `/start` - Главное меню с кнопками
- `/promo` - Ручная проверка промокодов
- `/server` - Статистика сервера
- `/steam` - Скидки в желаемом
- `/help` - Справка

### Кнопки меню:
- 🖥 Статистика сервера
- 💰 Баланс HostVDS
- 🎮 Скидки Steam
- 🔍 Промокоды
- 📦 Инвентарь Steam
- ⭐ Уровень Steam
- 📚 Помощь

## 🔔 Автоматические уведомления

Бот автоматически проверяет промокоды каждые 5 минут и отправляет уведомления о новых находках в ваш Telegram чат.

Интервал можно изменить в `config.py`:
```python
PROMO_CHECK_INTERVAL = 300  # секунды (5 минут)
```

## 🛠 Расширение функционала

### Добавление новых функций

1. Создайте новый обработчик в `bot/handlers/`
2. Добавьте роутер в `bot/main.py`
3. Добавьте кнопку в главное меню

### Пример добавления команды:

```python
# bot/handlers/new_feature.py
from aiogram import Router, F
from aiogram.types import CallbackQuery

router = Router()

@router.callback_query(F.data == "new_feature")
async def new_feature_handler(callback: CallbackQuery):
    await callback.message.answer("Новая функция!")
```

## ⚠️ Важные замечания

1. **Безопасность**: Не передавайте файлы с паролями и токенами третьим лицам
2. **Steam Guard**: Для полной функциональности нужен `shared_secret`
3. **HostVDS Server ID**: Можно найти в панели управления my.hostvds.com
4. **Лимиты API**: Steam может ограничивать частые запросы
