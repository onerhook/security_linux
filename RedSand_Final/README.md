# RedSand Secure v2.0

**Локальная система анализа вредоносного ПО с максимальной безопасностью**

## 🛡️ Особенности

- **Полная изоляция** - автоматическое отключение сети и блокировка фаервола
- **12 типов угроз** - классификация ransomware, stealer, miner, RAT, worm, botnet, rootkit, spyware, adware, trojan, dropper, keylogger
- **MITRE ATT&CK** - сопоставление тактик противника
- **Полиморфный анализ** - генерация вариантов образцов
- **Экстренная защита** - модуль Panic Button для мгновенной остановки
- **Анти-песочница** - обход техник обнаружения ВМ
- **Сетевая эмуляция** - безопасный DNS/HTTP сервер
- **Подробные отчеты** - JSON, HTML (интерактивный), TXT

## 🚀 Быстрый старт

### Требования
- Windows 10/11 (для полного функционала)
- Python 3.9+
- Права администратора

### Установка
```bash
# Клонирование репозитория
git clone <repository_url>
cd RedSand_Final

# Установка зависимостей
pip install psutil pefile yara-python
```

### Использование

#### Анализ файла
```bash
python redsand_secure.py suspicious.exe
```

#### Анализ с полиморфными вариантами
```bash
python redsand_secure.py malware.dll --poly
```

#### Генерация тестовых симуляторов
```bash
python redsand_secure.py --generate-test-samples
```

## 🔒 Безопасность

### Автоматическая изоляция
1. **Отключение сети** - все адаптеры (Wi-Fi, Ethernet) отключаются
2. **Блокировка фаервола** - весь входящий/исходящий трафик блокируется
3. **Эмуляция сети** - локальные DNS/HTTP серверы для образца

### Экстренное восстановление
- При критических действиях активируется **Panic Button**
- Мгновенное убийство подозрительных процессов
- Принудительное восстановление сети

## 📊 Типы определяемых угроз

| Тип | Описание | Риск |
|-----|----------|------|
| Ransomware | Шифрование файлов, выкуп | Критический |
| Stealer | Кража паролей, данных | Высокий |
| Miner | Майнинг криптовалюты | Средний |
| RAT | Удаленный доступ | Критический |
| Worm | Сетевое распространение | Высокий |
| Botnet | DDoS, спам | Высокий |
| Rootkit | Скрытие в ядре | Критический |
| Spyware | Слежка за пользователем | Средний |
| Adware | Навязчивая реклама | Низкий |
| Trojan | Маскировка под легитимное ПО | Высокий |
| Dropper | Загрузка других угроз | Средний |
| Keylogger | Перехват клавиш | Высокий |

## 🔧 Модули

### Panic Button
Мгновенная остановка при обнаружении:
- Шифрования файлов
- Массового удаления
- Подозрительной сетевой активности
- Инъекций кода

### Poly Engine
Генерация полиморфных вариантов для:
- Тестирования эвристик
- Обхода сигнатурного анализа
- Проверки устойчивости детектирования

### Threat Classifier
Классификация на основе:
- Статических паттернов
- Динамического поведения
- MITRE ATT&CK mapping

### Network Emulator
Безопасная эмуляция:
- DNS сервер (все домены → 127.0.0.1)
- HTTP сервер (фейковые ответы)
- Перехват запросов к C&C
