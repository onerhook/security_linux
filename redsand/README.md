# 🛡️ RedSand - Система анализа вредоносного ПО

**Локальная песочница для безопасного анализа подозрительных файлов**

## 📋 Описание

RedSand - это автономная система для анализа вредоносного программного обеспечения, работающая локально на вашем компьютере без необходимости в серверной инфраструктуре. Система обнаруживает подозрительное поведение, извлекает индикаторы компрометации (IOC) и формирует подробные отчеты.

## ✨ Возможности

### 🔬 Статический анализ
- Вычисление хешей (MD5, SHA1, SHA256)
- Анализ PE-заголовков (для Windows exe/dll)
- Извлечение строк (ASCII, Unicode)
- Сканирование YARA правилами
- Расчет энтропии секций
- Обнаружение подозрительных импортов API

### 🎭 Модуль "Анти-песочница"
- Эмуляция активности пользователя (движение мыши, нажатия клавиш)
- Подмена информации об оборудовании
- Добавление фейковых записей в реестр
- Эмуляция распространенных процессов
- Манипуляции со временем для обхода проверок

### 🌐 Сетевая эмуляция
- Локальный DNS-сервер (порт 5353)
- HTTP-сервер для эмуляции веб-трафика
- Безопасная эмуляция интернета
- Перехват и логирование всех сетевых запросов
- Автоматическое обнаружение подозрительных доменов

### 💾 Анализ памяти
- Создание дампов памяти процессов
- Обнаружение инъекций кода
- Поиск shellcode паттернов
- Выявление регионов RWX памяти
- Извлечение IOC из памяти (URL, IP, пути)

### 📊 Формирование отчетов
- JSON формат для машинной обработки
- Интерактивный HTML отчет с визуализацией
- TXT формат для быстрого просмотра
- MITRE ATT&CK mapping
- Извлечение и группировка IOC

## 🚀 Быстрый старт

### Требования
- **ОС**: Windows 10/11 (для полного функционала)
- **Python**: 3.9+
- **Права**: Администратор (для анализа памяти и перехвата API)

### Установка зависимостей

```bash
pip install pefile yara-python
```

### Запуск анализа

```bash
python redsand.py путь_к_файлу.exe
```

### Пример использования

```bash
# Анализ подозрительного exe файла
python redsand.py C:\Downloads\suspicious.exe

# Анализ DLL библиотеки
python redsand.py C:\Temp\payload.dll
```

## 🔍 Как это работает

1. **Статический анализ**: Файл анализируется без запуска - вычисляются хеши, извлекаются строки, проверяются YARA правила

2. **Подготовка окружения**: Модуль анти-песочницы создает реалистичную среду - эмулирует процессы, активность пользователя, изменяет реестр

3. **Сетевая эмуляция**: Запускаются локальные DNS и HTTP серверы для безопасного перехвата сетевой активности

4. **Выполнение**: Образец запускается в изолированной среде (требуется Windows VM для полной изоляции)

5. **Мониторинг**: Все действия образца логируются - файлы, реестр, сеть, процессы

6. **Анализ памяти**: Создаются дампы памяти, ищутся инъекции кода и shellcode

7. **Формирование отчета**: Генерируется вердикт, извлекаются IOC, создается отчет

## ⚠️ Предупреждения безопасности

1. **Запускайте только в изолированной среде** (VM, песочница)
2. **Не анализируйте образцы на основной системе**
3. **Отключите сеть перед анализом** (используйте сетевую эмуляцию)
4. **Требуются права администратора** для полного функционала
5. **Сохраняйте образцы** для дальнейшего анализа и отчетности

## 🔧 Расширение функционала

### Добавление YARA правил

Поместите `.yar` файлы в папку `rules/`:

```yara
rule Emotet_Dropper {
    strings:
        $s1 = "emotet" nocase
        $s2 = "loader" nocase
    condition:
        any of them
}
```

### Интеграция с VirusTotal

Добавьте API ключ в конфигурацию для автоматической проверки хешей.
